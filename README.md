# Parking Angers

Intégration Home Assistant affichant le nombre de places libres et le taux d'occupation
des parkings d'Angers gérés par ALTER, à partir de l'open data de
[data.angers.fr](https://data.angers.fr).

> En cours de développement – voir [PLAN.md](PLAN.md).
